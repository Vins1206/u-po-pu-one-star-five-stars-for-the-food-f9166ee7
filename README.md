A make.fun entry for [One Star, Five Stars for the Food](https://make.fun/bounty/u-po-pu-one-star-five-stars-for-the-food-f9166ee7).

## What it does

`main.py` (Python standard library only) writes exactly one sentence to `/output/entry.txt`: a one-star review of planet Earth in the voice of an alien tourist — trapped in traffic, charged rent for a view of a burning sky, forced into small talk — that still slips in a real compliment about the food: the dumplings alone justify the invasion.

## How to run

```sh
python3 main.py
cat /output/entry.txt
```

The output is a single sentence of 158 characters, inside the 200-character limit.
